# 我的工作台 V1 技术实现规格

> **交付对象：Cursor / Codex**  
> **项目目录：** `D:\Apps\work-studio`  
> **技术栈：** Vue 3 + TypeScript + Vite + Element Plus + Less + Node.js + SQLite  
> **核心编辑器：** 项目需要的 AiEditor 可以从 D:\Apps\vault-wallpaper 找到代码，已经实现了AI接入。

---

## 1. 产品目标

我的工作台是一个**本地优先（local-first）的个人工作台**，不是传统复杂 Todo / Notion 产品。

核心理念：

> **左侧负责“我要做什么”，右侧负责“我正在想什么”。**

```text
┌──────────────────────────┬─────────────────────────────────┐
│  需要做的事情            │  AiEditor                       │
│                          │                                 │
│  ○ 修改首页              │  随手记录 / 粘贴 / AI 内容       │
│  ○ 检查接口              │                                 │
│  ○ 提交 GitHub           │                                 │
│                          │                                 │
│  ✓ 买牛奶                │                                 │
│  ✓ 整理照片              │                                 │
└──────────────────────────┴─────────────────────────────────┘
                 左 50% / 右 50%
```

# 2. 实施原则

1. 这是重新创建项目。
2. 第一阶段必须先检查现有项目结构、`package.json`、路由、AiEditor 集成以及已有 AI API 接入代码。
3. 必须尽可能复用现有 AI API 和项目已有代码，不重复实现已有能力。
4. 第一版为单机、本地使用，不需要登录、用户系统或云端数据库。
5. 数据库使用 **SQLite**。
6. 不使用 Redis / MongoDB / MySQL / PostgreSQL。
7. SQLite 推荐使用 `better-sqlite3`。
8. 数据库文件放在项目 `data` 目录中。
9. 右侧 AiEditor 不提供手动保存按钮。
10. AiEditor 内容变化后自动保存。
11. Todo 删除采用软删除，不能直接物理删除。
12. V1 控制范围，优先完成稳定、快速、低认知负担的核心体验。
13. 所有新增代码必须遵循现有项目代码风格。
14. 不要为了 V1 引入复杂架构、ORM、状态管理框架或额外服务。

# 6. 数据库设计

## 6.1 todos

```sql
CREATE TABLE IF NOT EXISTS todos (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  content TEXT NOT NULL,
  completed INTEGER NOT NULL DEFAULT 0,
  deleted INTEGER NOT NULL DEFAULT 0,
  sort_order INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  completed_at TEXT
);
```

### 字段约定

| 字段 | 说明 |
|---|---|
| `id` | 自增主键 |
| `content` | Todo 内容 |
| `completed` | `0/1` |
| `deleted` | `0/1`，删除必须设置为 `1` |
| `sort_order` | 列表排序 |
| `created_at` | 创建时间 |
| `updated_at` | 更新时间 |
| `completed_at` | 完成时间，未完成时可以为 `NULL` |

时间统一使用 ISO 8601。

---

## 6.2 notes

```sql
CREATE TABLE IF NOT EXISTS notes (
  id INTEGER PRIMARY KEY,
  content TEXT NOT NULL DEFAULT '',
  updated_at TEXT NOT NULL
);
```

V1 永远只维护：

```text
id = 1
```

也就是说：

> 右侧 AiEditor 本质上是一个长期存在的“永久临时文档”。

首次启动时自动创建。


- Todo 查询

```text

PostgreSQL
```

# 8. REST API

V1 API：

```text

POST   /api/todos/import
```

---

## 8.1 GET /api/todos

默认：

```text
deleted = 0
```

排序：

```text
未完成 → 已完成
```

同状态下：

```text
sort_order ASC
```

---

## 8.2 POST /api/todos

创建一个 Todo。

示例：

```json
{
  "content": "修改首页 UI"
}
```

后端自动生成：

- id
- created_at
- updated_at
- sort_order

---

## 8.3 PUT /api/todos/:id

支持更新：

```json
{
  "content": "修改首页 UI",
  "completed": true,
  "deleted": false
}
```

完成时：

```text
completed = 1
completed_at = 当前时间
```

恢复未完成：

```text
completed = 0
completed_at = NULL
```

---

## 8.4 DELETE /api/todos/:id

注意：

> **不能执行物理 DELETE。**

实际执行：

```text
deleted = 1
updated_at = 当前时间
```

---

## 8.5 POST /api/todos/import

接收：

```json
{
  "text": "修改首页\n检查接口\n提交代码"
}
```

后端：

1. 按换行拆分
2. trim
3. 过滤空行
4. 批量创建 Todo

例如：

```text
修改首页 UI

检查接口


提交 GitHub
```

结果：

```text
修改首页 UI
检查接口
提交 GitHub
```

---

## 8.6 PUT /api/todos/reorder

建议：

```json
{
  "ids": [3, 1, 5, 2, 4]
}
```

后端按照数组顺序重新生成：

```text
sort_order
```

---

## 8.7 GET /api/note

返回：

```json
{
  "id": 1,
  "content": "...",
  "updatedAt": "..."
}
```

---

## 8.8 PUT /api/note

请求：

```json
{
  "content": "当前 AiEditor 内容"

```

# 16. AiEditor 自动保存

这是 V1 最重要的技术细节之一。

不能：

```text
input
↓
API
```

因为用户每敲一个字都会请求后端。

必须：

```text
用户输入
   ↓
Editor change
   ↓
debounce 500ms
   ↓
PUT /api/note
   ↓
SQLite
   ↓
显示“✓ 已保存”
```

---

## 16.1 debounce

逻辑：

```text
输入 A
↓
等待 500ms

500ms 内又输入 B
↓
取消之前 timer
↓
重新等待 500ms

500ms 没有变化
↓
执行保存
```

---

## 16.2 保存状态

推荐：

```text
编辑中
```

然后：

```text
保存中…
```

成功：

```text
✓ 已保存 · 10:42
```

失败：

```text
⚠ 保存失败
```

失败时：

> 绝对不能清空编辑器内容。

# 26. 最终产品原则

我的工作台不是 Notion。

也不是完整项目管理系统。

它应该：

```text
打开
 ↓
马上看到我要干什么
 ↓
右边马上开始记录
 ↓
不用保存
 ↓
不用登录
 ↓
不用分类
 ↓
不用建 Workspace
 ↓
不用建 Folder
```

核心：

```text
┌──────────────────────┐
│       我的工作台          │
├──────────┬───────────┤
│ Action   │ Scratchpad│
│          │           │
│ 我要做什么 │ 我正在想什么 │
│          │           │
└──────────┴───────────┘
```

**左边解决行动，右边解决思考。**

本地存储、自动保存、无登录、低认知负担，是 V1 的核心。
