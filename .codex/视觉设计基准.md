# 1. 设计目标

我的工作台不是传统 Todo App，也不是 Notion Dashboard。

它是一个：

> **极简、安静、快速、本地优先的个人 AI 工作台。**

核心关系：

```text
左侧
Action
我现在要做什么

        +

右侧
Scratchpad
我现在在想什么
```

产品视觉目标：

- 颜值优先
- 极简
- 高级
- 安静
- 有空间感
- 编辑器沉浸
- 低认知负担
- 少装饰
- 少层级
- 少颜色
- 少按钮
- 强排版
- 微妙动效

设计关键词：

```text
Premium Minimalism
Editorial Typography
Spatial UI
Soft Glass
Quiet Interface
Apple-like Restraint
Linear-like Density
Craft-like Editing
Raycast-like Interaction
```

**注意：**

不是复制 Apple / Linear / Craft / Raycast 的具体 UI，而是吸收这些产品优秀的设计原则，形成 我的工作台自己的视觉语言。

# 3. 核心设计原则

## 3.1 空间优先

不要把整个页面塞满。

页面必须保留大量留白：

```text
Content
↓
Spacing
↓
Content
↓
Spacing
```

而不是：

```text
Card
Card
Card
Card
Card
```

---

## 3.2 排版优先于装饰

高级感主要来自：

- 字体
- 字重
- 字号
- 行高
- 留白
- 对齐
- 灰度
- 层级

而不是：

- 渐变
- 阴影
- 彩色图标
- 大圆角
- 复杂背景
- 大量玻璃效果

---

## 3.3 Element Plus 只负责能力，不负责最终视觉

可以使用：

- Dialog
- Message
- Notification
- Dropdown
- Popover
- Input

但：

> **不要直接使用 Element Plus 默认视觉。**

需要通过 Less 对其进行视觉重构。

例如：

```text
Element Plus Dialog
        ↓
自定义 我的工作台 Dialog 视觉
```

```less
@color-text-tertiary: #A3A3A3;
@color-border: #EAEAE7;
@color-border-light: #F0F0ED;
@color-accent: #007AFF;
```

## 5.1 页面背景

```text
#F7F7F5
```

作用：

> 给页面提供非常轻的暖灰底色。

不要使用纯：

```text
#FFFFFF
```

作为整个页面背景。

---

## 5.2 内容区域

```text
#FFFFFF
```

Todo / Editor 工作区域使用白色。

---

## 5.3 主文字

```text
#171717
```

不要使用纯黑：

```text
#000000
```

避免视觉过重。

---

## 5.4 次级文字

```text
#777777
```

---

## 5.5 弱文字

```text
#A3A3A3
```

用于：

- placeholder
- 完成状态
- 辅助说明
- 最后保存时间

---

## 5.6 边框

```text
#EAEAE7
```

边框必须非常轻。

不要出现：

```text
#CCCCCC
```

这种明显灰线。

## 5.7 Accent

全局只使用一个主要 Accent：

```text
#007AFF
```

用于：

- 当前状态
- hover
- focus
- 添加按钮
- 当前过滤器
- 重要交互

不要大面积使用蓝色。

# 7. 间距系统

采用比较宽松的空间系统。

建议基准：

```text
4
8
12
16
20
24
32
40
48
64
```

常用：

```text

区域间距：24 ~ 32px
Todo 间距：8 ~ 12px
按钮内部：8 ~ 12px
编辑器内边距：40 ~ 56px
```

不要让内容贴边。

---

# 8. 圆角系统

整体使用中等偏小圆角。

推荐：

```less
@radius-sm: 6px;
@radius-md: 10px;
@radius-lg: 14px;
@radius-xl: 18px;
```

原则：

- Todo 行：10px 左右
- Dialog：16px 左右
- 浮层：12px 左右
- 主窗口：如果现有项目环境允许，可使用 16~20px

不要使用：

```text
32px
40px
50%
```

这种过度圆润的 SaaS 风格。

---

# 9. 阴影系统

阴影必须非常轻。

推荐：

```css
box-shadow:
  0 8px 30px rgba(0, 0, 0, 0.06);
```

浮层：

```css
box-shadow:
  0 12px 40px rgba(0, 0, 0, 0.10);
```

原则：

> 用户应该“感觉到层次”，而不是“看到一团阴影”。

禁止：

```text
重阴影
彩色阴影
大面积发光
Neon Shadow
```

# 20. Editor 快捷提示

可以保留一个非常轻的空状态引导：


# 21. Editor 内容区域


# 22. Glass / 毛玻璃

只允许在浮层使用。

适用：

- 右键菜单
- Dropdown
- Popover
- 浮动工具栏

例如：

```css
background: rgba(255, 255, 255, 0.78);
backdrop-filter: blur(20px);
-webkit-backdrop-filter: blur(20px);
border: 1px solid rgba(255,255,255,0.65);
```

禁止：

> 主页面所有区域都使用毛玻璃。

# 33. 设计检查标准

Cursor 完成 UI 后，必须自检：

### 第一眼

打开页面 1 秒内：

> 能不能感觉这是一个高级、简洁的生产力工具？

---

### 第二眼

是否明显存在：

```text
左边 = 我要做什么
右边 = 我要记录什么
```

---

### 第三眼
